# Dali AI XTTS Voice

ZeroGPU Gradio Space for Dali AI voice cloning with XTTS-v2.

The Space exposes the `/synthesize` API used by the Dali AI Vercel backend.

## Model

Coqui XTTS-v2 supports Arabic and multilingual voice cloning from a short reference clip.
